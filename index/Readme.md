# 🎫 Ticket & Equipment Management System

A web-based **IT Service Management System** designed to manage technical support requests and IT equipment efficiently.  

This system uses **role-based access control** to provide different dashboards and permissions for Administrators, Technical Staff, and Users.

---

## 📌 Brief Introduction

This project simulates a real-world **IT Helpdesk System** commonly used in schools and organizations.

It allows users to:

- Submit technical support tickets  
- Track ticket status  
- Manage IT equipment inventory  
- Assign technicians to resolve issues  

The system helps improve workflow, organization, and communication between IT staff and users.

---

## 👥 User Roles

### 🔴 Administrator
- Manage accounts
- Manage equipment
- View all tickets
- Approve, assign, and delete tickets
- View dashboard statistics

---

### 🟡 Technical Staff
- View assigned tickets
- Update ticket status
- Manage equipment

---

### 🟢 User
- Submit tickets
- View ticket status
- View equipment (read-only)

---

## ⚙️ System Features

- Secure login authentication
- Role-based dashboards
- Ticket tracking system
- Equipment management module
- Real-time statistics
- Responsive UI design
